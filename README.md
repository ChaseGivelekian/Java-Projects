# Java Projects

## Description
This repository contains various Java projects that I am using to practice for BPA states.

## Projects
- [Drinks—](Drinks)A program that connects to the cocktail API and returns all the categories of drinks. From that the user can select a category and get all the drinks in that category. The user can then select a drink and get the recipe for that drink. It uses the [Cocktail API](https://www.thecocktaildb.com/api.php) to get the data.
- [Excel Reader-](ExcelReader)A program that reads an Excel file and formats the data into a sqlite database. It uses the Apache POI library to read the Excel file and the sqlite library to write to the database.
- [Sports Results Notifier-](SportsResultsNotifier)A program that scrapes the [Basketball Reference](https://www.basketball-reference.com/boxscores/) website for the latest NBA game results and sends a notification to the user via email. It uses the Jsoup library to scrape the website and the JavaMail library to send the email.
- [Habit Logger-](HabitLogger)A program that allows the user to log their habits and track their progress. The user can add, edit, delete, and view their habits. It uses the sqlite library to store the data.
